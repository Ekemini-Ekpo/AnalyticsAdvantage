# Analytics Advantage — Machine Learning Projects

## Overview
Applied analytics projects using logistic regression, decision trees, 
and random forests to solve real business problems. Built during 
Georgetown McDonough's Analytics Advantage course, Spring 2026.

## Projects

### 1. Employee Attrition Prediction
Predicted employee turnover using classification models. Analyzed key 
drivers of attrition including tenure, department, and satisfaction 
scores to surface actionable retention insights.
- **Methods:** Logistic Regression, Classification Trees, Random Forests
- **Files:** `employee_attrition_dataset.csv`, `example_predictions.csv`

### 2. Marketing Campaign Efficiency
Analyzed marketing campaign performance data to identify which campaign 
types and channels drive the highest conversion efficiency.
- **Methods:** Exploratory Data Analysis, Classification Modeling
- **Files:** `MarketingCampaignEfficiency.csv`

### 3. Case Analysis — Efes & Big Mart
Business case analyses applying data-driven approaches to retail and 
consumer goods problems.
- **Files:** `EfesCaseWeek2.ipynb`, `Big Mart Dataset.csv`

## Tools
Python, R, Pandas, Scikit-learn, Excel
